# EmotionSense-AI

## Multimodal Emotion Recognition Using Deep Learning

EmotionSense-AI is a multimodal emotion recognition system that predicts human emotions from **Image, Audio, and Text** inputs using Deep Learning models. The system combines multiple modalities to improve emotion prediction accuracy and provides an interactive Streamlit-based user interface.



## Features

* Image Emotion Detection
* Audio Emotion Detection
* Text Emotion Detection
* Fusion-Based Emotion Prediction
* Interactive Streamlit Web Application
* Real-Time Prediction Interface


## Models Used

### Image Models

* EfficientNet
* MobileNetV2
* VGG16
* Custom CNN

### Audio Models

* CNN
* LSTM

### Text Models

* BERT
* LSTM
* Transformer

### Fusion Model

* Late Fusion Strategy for Multimodal Emotion Prediction
